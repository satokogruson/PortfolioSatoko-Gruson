# Satoko Gruson Portfolio

## About this site
Personal UX/PM portfolio, deployed to GitHub Pages at
satokogruson.github.io/PortfolioSatoko-Gruson/. The site is password-protected;
don't remove or weaken the password protection.

## Design system
- Background: #FCFAF8 (warm off-white)
- Text: #3A312C (dark charcoal)
- Accent: #C97B6E (dusty rose)
- Headings: Playfair Display (serif)
- Section labels: "— LABEL IN CAPS" style
- New pages must match the existing case study layout

## Working rules
- Explain what you plan to change before large edits
- Keep case study content accurate; don't invent metrics or results
- Use clear, descriptive commit messages
